# Exercicio 2 - Barra de Botoes

Exercício da Aula 2 (BRADEMO) - Introdução ao Flutter Framework
Prof. Luiz Gustavo Diniz de Oliveira Véras

## Widgets trabalhados
Row, Column, Icon e Container (barra de botoes)

## Como executar

1. Tenha o Flutter SDK instalado (https://docs.flutter.dev/get-started/install).
2. Extraia este zip.
3. Dentro da pasta do projeto, rode:

```bash
flutter pub get
flutter run
```

O código principal está em `lib/main.dart`.
