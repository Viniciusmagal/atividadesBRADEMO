## Como executar

1. Tenha o Flutter SDK instalado (https://docs.flutter.dev/get-started/install).
2. Extraia este zip.
3. Dentro da pasta do projeto, rode:

```bash
flutter pub get
flutter run
```

O código principal está em `lib/main.dart`.
